# 引書店 Discord Bot 使用說明

這個 bot 主要用來查詢「引書店 Podcast」已整理好的集數、書籍、概念與逐字稿線索。

## 使用方式

- 私訊 bot，直接輸入自然語言問題。
- 在 Discord 伺服器中，先 `@引書店機器人` 再輸入問題。
- 範例：`@引書店機器人 有沒有聊過職業倦怠？`
- 範例：`@引書店機器人 哪幾集提到納瓦爾？`
- 範例：`@引書店機器人 EP.375 在講什麼？`

## 詢問建議

- 不知道怎麼問時，直接輸入一句自然語言問題即可。
- 想查書名、概念、主題或逐字稿關鍵字，也都直接問。
- 想看目前有哪些集數可查，可以問「目前有哪些集數可以查？」。
