# 引書店 Discord Bot 使用說明

這個 bot 主要用來查詢「引書店 Podcast」已整理好的集數、書籍、概念與逐字稿線索。

## 可用指令

- `/ping`
  - 確認 bot 是否在線。
  - 範例：`/ping`

- `/ask question`
  - 用自然語言詢問節目內容、書籍、主題或概念。
  - 查書名、主題、概念、某一集在講什麼、目前有哪些集數可查，都用這個。
  - 範例：`/ask 有沒有聊過職業倦怠？`
  - 範例：`/ask 哪幾集提到納瓦爾？`
  - 範例：`/ask EP.375 在講什麼？`

## 詢問建議

- 不知道怎麼問時，直接用 `/ask` 加一句自然語言問題。
- 想查書名、概念、主題或逐字稿關鍵字，也都用 `/ask`。
- 想看目前有哪些集數可查，也直接問 `/ask 目前有哪些集數可以查？`。
